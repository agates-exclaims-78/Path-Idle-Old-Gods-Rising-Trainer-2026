## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Path of Idle: Old Gods Rising**. This trainer enhances the game's automated progression systems by providing control over resources, gear development, combat outcomes, town upgrades, and stage progression. It is designed around the game's Godsworn teams, loot-driven progression, town management, and full-auto battles.

**Target Audience:** Players who want to reduce resource grinding, experiment with Godsworn classes and gear builds, accelerate town development, or explore the game's stages, towers, realms, and seasonal content with less repetition.

## 📖 Detailed Feature Guide

### Movement & Exploration

Path of Idle: Old Gods Rising is an idle RPG with automated battles rather than a character-controlled movement system. Select a mode or stage from the game interface, choose a Godsworn team, and allow the battle to run automatically. The trainer does not add manual movement controls.

### Tools & Inventory

Use inventory-related options after loot, equipment, crafting materials, or chests have been loaded. Gear rarity and equipment combinations are central to progression, so save valuable items before testing large-scale inventory changes. Disable resource options before crafting or opening chests if you want normal reward behavior restored.

### World & Environment

The main progression loop begins in the town on Blackreef Isle. Upgrade buildings, develop services, recruit and awaken exiles as Godsworn, then send teams into the available adventure modes. Trainer options for resources and upgrades are most effective after the relevant town feature has been unlocked.

### Combat & Weapons

Combat runs in full-auto real time. Assemble a team using the game's six classes, equip suitable gear, configure skills, and launch the selected activity. Activate combat options before starting a battle, then disable them after the encounter if you want to preserve normal progression balance.
